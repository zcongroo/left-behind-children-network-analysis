# Analysis scripts

- `1.correlation analyses.R` estimates item-level correlations and generates heatmaps for all three waves.
- `2.cross-sectional network analyses.R` estimates and compares the cross-sectional networks across the three waves and evaluates node predictability, centrality, and network stability.
- `3.cross-lagged panel network analyses.R` estimates the cross-lagged panel networks for T1 to T2 and T2 to T3 and evaluates node predictability, expected influence, and network stability.
